# Quote Response Parser Rules

견적답변 자동 가져오기는 OCR/텍스트 원문에서 확정 견적 행만 뽑아야 한다. 안내문과 조건부 금액은 사람이 읽기 위한 참고 정보일 뿐, 견적서 기본 행으로 승격하지 않는다.

## Base Row Sources

- `항공 요금`, `지상 요금`, `공동 경비 요금`처럼 명시된 요금 섹션의 bounded 그리드 금액을 우선한다.
- 항공 기본 행은 `항공 요금` 섹션 안의 `항공료`와 `TAX`에서만 만든다.
- 지상 기본 행은 `지상 요금` 또는 `개별 요금` 섹션 안의 `지상비`에서만 만든다.
- 공동 경비 기본 행은 `공동 경비 요금` 섹션 안의 `인솔자비`, `FOC`, `보험료`, `기타`에서만 만든다.
- `1인당 예상수익`은 표시용 행으로 유지하되 VAT, agency fee, ground profit에 중복 반영하지 않는다.

## Ignored Money Sources

다음 구간의 금액은 기본 견적 행으로 만들지 않는다.

- `비고사항`
- `대리점 공개`
- `최종 안내사항`
- `유효기간`
- `답변 첨부파일`
- 프로모션, 벌금, 조건부 특가, 선발권 조건, 인원 변동 안내
- 호텔 싱글차지, 불포함, 선택 옵션, 현지 추가비

## OCR Normalization

- `공동 경비 요금`, `공통 경비 요금`, `중간 경비 요금`은 같은 공동 경비 섹션으로 정규화한다.
- `보험료`가 OCR에서 `보료`, `부가세`처럼 깨져도 공동 경비 그리드 위치가 보험료 열이면 보험료로 본다.
- 공동 경비 합계가 있고 FOC/인솔자비/기타 일부만 잡힌 경우, 차액이 합리적인 보험료 후보면 누락 보험료로 복원한다.
- 뒤쪽 공동 경비/비고 구간의 `항공료` 텍스트가 앞쪽 항공 기본요금을 덮어쓰면 안 된다.

## Regression Fixtures

견적답변 이미지 fixture는 `tests/fixtures/quote-response/`에 둔다. 일정표 golden fixture 폴더에는 여행 일정 파일만 둔다.
